# Field Notes — jQuery Assignment 6

Sulukhan Aizharykova · SE-2529

A small herbarium with five linked pages demonstrating jQuery selectors, effects, DOM updates and animations.

[Open the GitHub Pages site](https://sulumate.github.io/web6_sulumate/)

## Run

Open `index.html` in a browser and use the navigation bar to move between parts. No install or build is needed. An internet connection is required for jQuery 3.7.1 from the CDN.

## Tasks

| Part | Page | Try it |
| --- | --- | --- |
| 1 · Tasks 0–1 | [Selectors](index.html) | Open the console for “jQuery is ready!”. Label the fern, then enter a CSS color and click Apply to change the sample paragraph. |
| 2 · Tasks 2–4 | [Effects](effects.html) | Show or hide a note, fade a poppy illustration and slide a panel. Each example has a toggle. |
| 3 · Tasks 5–7 | [DOM](dom.html) | Add a specimen at either end of the list, remove the last one, switch the image or reference link, and type a name and email to preview them. |
| 4 · Tasks 8–10 | [Animations](animations.html) | Run three square animations. Watch the sequence move right, move down, shrink and return. Each button can replay its example. |
| 5 · Task 11 | [Field guide](guide.html) | Click a specimen name to open its accordion panel. Select it again to close it, or pick another specimen. |

## Check the color exercise

On Selectors, type `red` in the Color field and click Apply. The sample paragraph turns red. Try `#2563eb` next. An invalid value shows an error and keeps the previous paragraph color.
